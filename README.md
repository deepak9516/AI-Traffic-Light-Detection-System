# AI Traffic Light Detection System

An AI-based smart traffic management system developed using Python, YOLOv8, and OpenCV.

## Features
- Real-time vehicle detection
- Lane-wise vehicle counting
- Dynamic traffic signal timing
- Emergency vehicle detection alert
- Traffic data logging using SQLite
- Video-based traffic analysis

## Technologies Used
- Python
- OpenCV
- YOLOv8
- NumPy
- SQLite
- Pygame

## How to Run
1. Install required libraries
2. Place traffic video file in project folder
3. Run the main.py file
